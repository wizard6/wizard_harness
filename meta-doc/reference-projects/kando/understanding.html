它是什么

跨平台桌面扇形 / marking 菜单：用方向选择代替点小按钮。整屏是目标；嵌套子菜单靠一条连续拖动手势穿过。

交互（要借的核心）

  • Marking：按住拖过扇区；进子菜单后菜单跟手；松手激活叶子
  • Point-and-click：点扇区任意处（Fitts）
  • Turbo / Hover：更快，本阶段不优先

边界

Kando 是 OS 级启动器。harness 只借几何与 marking 手势，用来快开插件，不复制全局钩子与键鼠宏。
