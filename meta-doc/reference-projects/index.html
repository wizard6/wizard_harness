理解 · 拆分 · 源仓 · NERvSDK

对照原则

  • 哲学优先于产品壳：只搬「怎么写 / 怎么浮现 / 怎么触发 / 怎么评测 / 怎么合成」；MCP、Dashboard、OAuth、Telemetry Host、Steam 工坊、QML 主题市场不进底座。
  • 边界清晰：session = 本轮说过什么；persona = 身份基线（soul.md）；memory = 跨会话经历；skills = 可发现的 SKILL.md 能力包；桌面绘图 = 壳的叠加表面，不是插件 HWND。
  • 本地可跑：默认无向量服务、无外部评测 SaaS、无 native D3D 宿主也能工作。
  • 分析与代码同步：改对应插件或桌面壳时，更新该项目拆分文的「已落地 / 刻意推迟」。
  • 绘图借模型不借引擎：分层窗口、z / 命中、Canvas 场景图、属性插值；不搬 GDI/D3D9/OpenGL/Qt。
