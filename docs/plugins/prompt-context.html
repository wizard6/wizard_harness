prompt-context — 模型可见上下文组装

组装 sections（→ system）、contexts（→ user 快照）、tools（→ 工具表）、variables（{{name}} 插值）。assemble 产出 PromptAssembly；apply 写入 session。本仓库没有 system-prompt 插件；DSH 里那块职责就是本插件。

id: prompt-context provides: promptContext inject: session

一句话：唯一负责「这一步模型该怎么被引导」的组装。agent-loop 必选本服务，每步 assemble + apply。

API

ctx.promptContext.section({ name, order, text })
ctx.promptContext.context({ name, order, text })
ctx.promptContext.variable('role', (ctx) => 'tester')
ctx.promptContext.tools((ctx) => tools.list())
ctx.promptContext.bind(agent.ctx).section({ ... })  // scoped 层
const asm = ctx.promptContext.assemble({ sessionId, scope })
ctx.promptContext.apply(sessionId, asm)
ctx.promptContext.setPersona(sessionId, '你是简洁助手')
ctx.promptContext.inspect()  // 素材 + 最近成品

落盘规则

组装项session 中的形态
sections（渲染后）message · role: system
contexts（渲染后）message · role: user（带 runtime context 前缀）
tools交给 llm.complete({ tools })，不直接 append

观测

弹窗左右对照：可获取素材与 拼接成品。inspect() 只读登记表。「试拼」才 assemble。默认身份基线由 persona 登记 persona:core（当前份 soul，live 函数）。

依赖：agent-loop 对本服务为必选 inject；缺 prompt-context 时 agent-loop 在 boot 阶段挂起。

prompt-context/assemble · prompt-context/apply · prompt-context/persona

ui.rpc：inspect / assemble。

给后续 AI

不要再造 system-prompt 插件或名为 systemPrompt 的服务。用量面板另插件。agent-loop 必选本服务。
