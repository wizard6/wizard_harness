pomodoro — 番茄钟

专注 / 短休 / 长休循环；独立弹窗 + 系统托盘「Open Pomodoro」入口。与通用 timer 调度插件分离。

id: pomodoro provides: pomodoro ui.rpc bundle: app

1. 用途与边界

一句话：给人用的番茄计时器，不是 cron/flow 调度器。

  • 管：专注·休息状态机、弹窗 UI、托盘快捷打开、pomodoro 服务快照与控制
  • 不管：workflow 定时、agent 工具（首版未登记 tools）、系统通知（后续可加）

桌面壳机制见 guides/desktop-shell。

2. 服务 API

服务名 POMODORO_SERVICE = 'pomodoro'。弹窗经 ui.rpc 调用下列方法。

方法作用
snapshot()当前阶段、剩余毫秒、已完成番茄数、配置
start()从 idle 进入专注，或恢复运行
pause() / resume()暂停 / 继续倒计时
reset()回到 idle，计数清零
skip()手动进入下一阶段
configure(patch)调整专注/休息时长与长休间隔

3. 配置（manifest.config）

键默认说明
focusMinutes25专注时长（分钟）
shortBreakMinutes5短休
longBreakMinutes15长休
longBreakEvery4每 N 个番茄后长休

4. 打开方式

  • 观测台 → 插件列表 → pomodoro → 打开窗口
  • 托盘右键 → Open Pomodoro
