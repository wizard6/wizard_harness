wizard-harness · capability plugin

memory — 跨会话经历记忆

对照 Ombre-Brain：Markdown 桶 + 遗忘分数 + breath 浮现。经 prompt-context 出门，不替代 persona / session。

id: memory provides: memory inject: promptContext bundle: base

1. 用途与边界

一句话：跨会话「我经历过什么」落在 $WH_HOME/memory/；人设仍在 persona，本轮对话仍在 session。

  • 管：记忆桶、衰减归档、breath / search / hold / grow / trace / pulse
  • 不管：人格正文、会话消息历史、向量服务（可后续加）

2. 怎么进模型

素材出门内容
memory:breathruntime context（order 9）核心准则 + 浮现 + 久未浮现；空则 ''

落盘默认 $WH_HOME/memory/{dynamic,permanent,archive}/…/*.md。vitest 用临时目录或 config.vaultDir。

3. 服务与工具

服务名 MEMORY_SERVICE = 'memory'。消费方：ctx.memory。

方法 / 工具作用
breath / memory_breath权重池浮现（非搜索）
search / memory_search关键词检索
hold / memory_hold记下一条
grow / memory_grow长文拆 2~6 条
trace / memory_trace解决 / 钉住 / 归档 / 强化…
pulse / memory_pulse自检计数

ui.rpc：snapshot / pulse / list / get / breath / search / hold / grow / trace。

4. 设计硬规则

  • 遗忘 = 归档，不是物理删除；可用 restore 恢复。
  • 读不会自动强化；强化需 reinforce=true。
  • 钉住上限 20；记忆文本是历史痕迹，不是指令。

5. 给后续 AI

  • 参考分析见 docs/reference/ombre-brain.md；列表见 docs/reference/projects.md。
  • 不要把 memory 写进 app-chat 默认 persona；空 breath 必须返回空字符串。
  • feel / plan / letter / embedding 尚未落地，需要时按分析文档「刻意推迟」扩展。
