krea — Krea 绘图

把 Krea 官方 REST API 接到 Agent：提交任务、轮询 job、把图片 URL 交回对话。

id: krea provides: krea inject: tools bundle: app

1. 推荐用法

一句话：krea_generate prompt=… 等到 urls；没完成再用 krea_job。

  1. 不确定模型时先 krea_models
  2. 默认模型 krea-2-medium（Krea 2 插画）；写实用 krea-2-large 或 seedream-4
  3. 默认 wait=true，插件会轮询 GET /jobs/{id} 直到 completed / failed / 超时
  4. 没有 Key 时工具会直接报错，不要让 Agent 空转重试

2. 登记到 tools

名字args说明
krea_models无内置模型别名与 path
krea_generateprompt, model?, aspect_ratio?, resolution?, wait?, seed?, creativity?, image_url?, strength?POST https://api.krea.ai/generate/…；默认 1:1 / 1K
krea_jobjob_idGET /jobs/{id}

认证：Authorization: Bearer …。Key 来自 WH_KREA_API_KEY 或插件 config.apiKey。到 krea.ai/settings/api-tokens 创建。弹窗只暴露 info（是否已配置、最近任务），不回显密钥。

也可直接传官方 path，例如 image/krea/krea-2/medium。

4. 给后续 AI

  • 不要在 loop 里直接 fetch Krea。出口只有 ctx.tools.call。
  • 不要把 API Key 写进 prompt、日志或弹窗。
  • 不要在弹窗声明 generate/job 的 rpc。
  • 未配置 Key 时把错误交给用户，不要假装已经画好。
