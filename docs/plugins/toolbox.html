toolbox — 配置驱动工具盒子

观测台打开「工具盒子」弹窗，点按卡片上的 运行 即可执行；工作区路径可改并会记住。Agent 仍通过 box.* 工具调用。

脚本类型

kind字段说明
shellcommand在 session.workspace（或 cwd）执行 shell；支持 {{message}}、{{path}}、{{workspace}} 占位符
open_pathpath在资源管理器中打开工作区内路径
open_urlurl用系统浏览器打开 URL

默认工具

  • box.open_folder — 打开工作区目录
  • box.git_push — git add / commit / push

配置示例

{
  "id": "toolbox",
  "config": {
    "cwd": "",
    "scripts": [
      {
        "name": "open_folder",
        "label": "打开文件夹",
        "kind": "open_path",
        "path": "{{path}}",
        "params": [{ "key": "path", "label": "子路径" }]
      },
      {
        "name": "git_push",
        "kind": "shell",
        "command": "git add -A && git commit -m \"{{message}}\" && git push"
      }
    ]
  }
}
