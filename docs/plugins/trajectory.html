wizard-harness · capability plugin

trajectory — 执行轨迹

session 记「说过什么」。本插件记「怎么跑出来的」：拼提示词、HTTP 请求、工具调用与返回、模型 complete。

id: trajectory provides: trajectory 可选 inject：llm / tools / loop / system-prompt
用途 步骤类型 服务 API 给后续 AI

1. 用途与边界

一句话：Agent 运行的审计账本。不替代 session，不发模型，不落盘，不存 apiKey。

  • 管：start / record / replay、弹窗回放
  • 不管：对话气泡、模型循环、HTTP 实际发送（由 llm adapter 回调写入）
run-start
  prompt { phase: apply }          ← system-prompt.apply
  prompt { phase: assemble, wire } ← llm 拼好的消息
  http { url, status, request }    ← 真请求才有（mock 没有）
  complete { text, toolCalls }
  tool { name, args, content, ok }
  prompt assemble …
  complete …
run-end

2. 步骤类型

kind谁写入data
run-start / run-endagent-loopmaxSteps / steps / text / error
promptsystem-prompt、llmapply 的文本；assemble 的 messages + wire
httpllm adapterurl、model、status、request.messages（无密钥）
tooltoolsname、args、callId、ok、content
completellmprovider、text、toolCalls

3. 提供的服务

服务名 TRAJECTORY_SERVICE = 'trajectory'。消费方：ctx.trajectory。

方法作用
start({ agentId?, sessionId? })开一条轨迹并设为 current
record(sessionId, kind, data)写入；无轨迹则按 session 新建
forSession / current / latest / list回放与列表
snapshot(id?)纯数据快照（弹窗 RPC 用；无 id 等同 latest）

弹窗：时间线（中文步骤名，点开看细节），ui.rpc：latest / list / snapshot。App demo 右栏经 app-ui 的白名单调同一服务。

4. 给后续 AI

  • 不要把轨迹条目写进 session（session 仍只有 turn / message / tool-result）
  • 新的执行步骤：在发生处 ctx.trajectory?.record，inject trajectory: false
  • HTTP 回调不要带 authorization
  • 时间线 CSS/脚本在 plugins/trajectory/src/view.ts；app-ui 有一份同步副本 traj-view.ts
