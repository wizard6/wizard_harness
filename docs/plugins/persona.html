persona — 人格 / 习惯 / 记忆

当前助手的人设档案。支持 AI 通过工具自生成人格（名字、风格、性格等元数据），正文经 prompt-context 出门。

id: persona provides: persona inject: promptContext bundle: base

1. 用途与边界

一句话：改默认人设只动本插件（或 $WH_HOME/persona.json）。AI 可用 persona_apply 一次性写入自生成人格。

  • 管：名称、元数据（角色/风格/语气/性格/边界/自述）、人格正文、习惯、相关记忆
  • 不管：跨会话经历桶（见 memory）、session 历史、loop 步进

2. 怎么进模型

素材出门内容
persona:coresystem section「我是谁」元数据 + 人格正文 + 习惯
persona:authoring-hintsystem section仍为默认人设时提示调用 persona_guide / persona_apply；定制后为空
persona:memoryruntime context钉住 + 最近 6 条未钉；空则 ''

落盘默认 $WH_HOME/persona.json（含 meta 字段）。旧文件无 meta 时自动补空对象，兼容升级。

3. 服务与工具

方法 / 工具作用
read / persona_read档案 + 预览 + 落盘路径 + 是否默认人设
guide / persona_guide自生成字段说明、模板、检查清单
apply / persona_apply一次性写入完整人格（推荐首次定制）
configure / persona_configure局部修改元数据或正文
save / configure弹窗保存（人类编辑）
remember / persona_remember记事实或追加习惯

persona_apply 必填 name、personality；建议同时提供 role、voice_style、traits。

4. 给后续 AI

  • 首次定制推荐：persona_read → persona_guide → persona_apply。
  • 微调用 persona_configure，不要重复 apply 整份覆盖除非有意重置。
  • 跨会话「经历」用 memory_hold，不要把一切都塞进 persona 短记忆。
  • 空记忆 / 空 hint 必须返回空字符串，不占 token。
