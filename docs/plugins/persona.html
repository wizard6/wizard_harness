persona — 人格 / 习惯 / 记忆

当前助手的人设档案。正文经 prompt-context 出门，不替代组装器。弹窗可改人格与习惯、钉住或删除记忆。

id: persona provides: persona inject: promptContext bundle: base

1. 用途与边界

一句话：改默认人设只动本插件（或本插件落盘的 $WH_HOME/persona.json）。不要写进 app-chat / loop。

  • 管：名称、人格、习惯、相关记忆；live section persona:core（order 2）与 context persona:memory（order 8）；工具 persona_remember
  • 不管：拼装顺序以外的配方、session 历史、loop 步进

2. 怎么进模型

素材出门内容
persona:coresystem section人格正文 + 习惯列表
persona:memoryruntime context全部钉住 + 最近 6 条未钉；空则 ''（不占 token）

落盘默认 $WH_HOME/persona.json。vitest 不落盘，除非 config.persistFile。

3. 服务与弹窗

服务名 PERSONA_SERVICE = 'persona'。消费方：ctx.persona。

方法作用
snapshot()档案 + 预览 + 当前 live agent 列表
save({ name?, personality?, habits? })改人格 / 习惯
addMemory / removeMemory / pinMemory相关记忆
remember({ text, kind?, pinned? })kind=habit 进习惯，否则进记忆

ui.rpc：snapshot / save / addMemory / removeMemory / pinMemory。不开放 remember（给工具用）。

工具 persona_remember：args.text 必填；可选 kind=memory|habit、pinned。

4. 给后续 AI

  • 不要再造 system-prompt 插件。人设出口只有 prompt-context。
  • 不要让 app-chat 在首次 send 传 loop.run({ persona })：setPersona 会另开 session:persona 段，和 persona:core 叠两份。
  • run.persona 仍是显式覆盖（结构改造 #2 未完）。默认路径不要用它。
  • 空记忆必须返回空字符串，不要写「暂无记忆」占 token。
