persona — 硅灵（身份基线）

soul.md 式 SystemPrompt：恒定人格核心，可保存多份并切换。不管理记忆。正文经 prompt-context 出门，本插件不替代组装器。

id: persona provides: persona inject: promptContext / tools（可选） bundle: base soul ≤ 3000 字

1. 用途与边界

一句话：硅灵是 Agent 的身份基线（类似 soul.md），不是记忆系统。跨会话经历用 memory；本轮对话用 session。

  • 管：多份 soul（名称 + markdown 正文）、当前份切换、3000 字上限、AI 新建/更新/切换工具
  • 不管：记忆、会话历史、loop 步进。不提供记忆系统，也不往上下文塞「相关记忆」

promptContext 与 tools 均为可选 inject：有则登记 persona:core / persona_*；没有也能单独加载，便于整插件替换。替换方只需仍 provides: persona，并按同样契约实现 soul()。

2. 怎么进模型

素材出门内容
persona:coresystem section当前份 soul（整段身份基线）
persona:authoring-hintsystem section仍为出厂单份默认硅灵时提示 create；定制或多份后为空

弹窗左侧切份，右侧编辑 soul，工具栏显示 xxx / 3000（Unicode 码点）。超限拒绝保存。

落盘 $WH_HOME/persona.json：{ version: 2, activeId, profiles[] }。旧版单档案（含 memories）启动时迁成一份 soul，记忆字段丢弃。

3. 服务与工具

方法 / 工具作用
list / persona_list全部硅灵：id、名称、字数、是否当前份
read / persona_read当前或 args.id 的 soul；不含记忆
guide / persona_guide写作模板与 3000 字清单
create / persona_create新建。必填 name；soul 或 personality/role/habits 等拼 markdown。默认切为当前份
update / persona_update更新当前或指定 id
activate / persona_switch切换当前份
save / remove弹窗保存当前份 / 删除（至少留一份）
soul()当前份正文；组装器读这个，不读其它插件

已移除 persona_remember / addMemory。经历类事实请 memory_hold。

4. 给后续 AI

  • 新建：persona_list → persona_guide → persona_create（soul ≤ 3000）。
  • 更新当前份：persona_update；换人设：persona_switch id=…。
  • 不要往 soul 里写会话记忆、待办或项目流水。那些归 memory / session。
  • 不要新增 system-prompt 插件。换实现就换本插件，保持服务名 persona。
  • 空 authoring-hint 必须返回空字符串。
