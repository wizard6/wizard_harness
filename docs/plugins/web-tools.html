web-tools — 网页工具套件

搜索 + 阅读。对齐常见 agent 的渐进披露：先大纲（~标题树），再按节读取。默认不把整页灌进上下文。

id: web-tools provides: webTools inject: tools bundle: app

1. 推荐用法

一句话：web_search → web_outline → web_read heading=…。要结构用 mode=markdown，只要正文用 mode=text。

  1. 搜索只要 title / url / snippet
  2. outline 只返回标题树和每节体积
  3. read 指定 heading 只拿那一节；长页未指定 heading 时返回预览 + 大纲，拒绝倾倒
  4. 页内关键词用 web_find，再回头 read 那一节

2. 登记到 tools

名字args说明
web_searchquery, count?默认 DuckDuckGo HTML；有 WH_BRAVE_API_KEY 走 Brave；有 WH_SEARX_URL 走 SearXNG
web_outlineurl标题树 + chars / approxTokens
web_readurl, heading?, mode?, offset?, max_chars?markdown 保留标题/列表/链接；text 去掉。默认 max 6000 字符
web_findurl, query页内短摘录 + 所属章节

同 URL 内存缓存 10 分钟，outline 后再 read 不重复抓取。拒绝 localhost / 私网（防 SSRF）。弹窗只暴露 info。

3. 给后续 AI

  • 不要在 loop 里直接 fetch。出口只有 ctx.tools.call。
  • 不要默认返回全文 HTML。结构用 markdown，纯文本用 text，长页走 outline。
  • 不要在弹窗声明 search/read 的 rpc。
  • 无无头浏览器 / 无 PDF。JS 渲染站可能是空壳。
