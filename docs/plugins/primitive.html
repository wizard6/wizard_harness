primitive — 思考提示词仓库

更小维度的提示词原子（Primitive），不是 Skill。仓库 + 树/链 + 内部路由预览；不注入 prompt-context。

id: primitive provides: primitive bundle: app tools: primitive_*

边界

一句话：Skill 是整份说明书、常驻/按需直接注入上下文。Primitive 是更小维度的思考提示词；选用哪几条走内部路由或 AI 工具，不准整包注入。
  • 管：注册表、标签、树、双向链、内部路由 route、只读弹窗（仓库 / 路由两页）、可选工具 primitive_*
  • 已认可标签（英文、绿色）：behavior / evaluate / guide
  • 不管：写入仓库、注入 prompt-context、影子轨、问题分类全套、元评价

含义：把「怎么想」拆成比 Skill 更小的提示词原子，供框架以后按问题类编排。目标是积累思考经验，不是给 Agent 再喂一份说明书去挽救单次任务。

和 skills 的差

skillsprimitive
粒度一份 SKILL.md一小段思考约束
进模型目录 + alwaysApply 直接注入本切片不注入
结构目录文件树（分解）+ 有向边双向索引

服务

服务名 PRIMITIVE_SERVICE = 'primitive'。弹窗 ui.rpc 放行下列只读方法。

snapshot全部条目摘要 + 标签计数
list全部摘要（无正文）
get(id)含 body 的一条
tags标签及条数（含 thinkKind）
listByTag(tag)按标签或 thinkKind 过滤；空字符串=全部
tree森林：根节点及 children
links有向边列表（source / target / kind）
neighbors(id)父、子、链上另一端（dir: in|out）
route(opts?)内部路由：hint / startId / tag → 有限步骤（guide→evaluate→behavior，默认负荷 5）

内部路由（简单）

入口（线索 / 起点 / 标签 / 否则树根）→ 树分解一层 → 沿双向链（then 优先）→ 按 guide → evaluate → behavior 排序 → 负荷封顶。弹窗「路由」页可试跑并看图。这不是工作流，不管「做什么」。

AI 怎么调

工具：primitive_route → 只对返回 id 调 primitive_get；关系用 primitive_neighbors；列表用 primitive_list。
