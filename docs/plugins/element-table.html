element-table — 通用周期元素表 v0.3

多 catalog 框架：游戏机制、小说元素… 同一套周期网格 / 正式·演示分层 / 登记 API。

id: element-table provides: elementTable (+ mechanicsTable 兼容) 托盘: Element Table

内置 catalog

  • mechanics — 游戏机制（动机 / 挑战 / 经济 / 空间 / 时间 / 社交）
  • novel — 小说元素（人物 / 情节 / 世界 / 主题 / 文笔 / 节奏）

正式库均为空；演示集各 24 格样例。数据在 plugins/mechanics-table/src/catalogs/<id>/。

扩展新表（如影视）

ctx.elementTable?.registerCatalog({ id: 'film', title: '影视元素', periods: 4 });
ctx.elementTable?.registerGroup('film', { id: 'shot', symbol: 'Sh', name: '镜头', tone: 'space' });
ctx.elementTable?.registerElement({
  catalogId: 'film',
  id: 'film-cut',
  symbol: 'Cu',
  name: '剪辑点',
  group: 'shot',
  period: 1,
  kind: 'formal',
  demo: 'generic',
});

或加内置目录

plugins/mechanics-table/src/catalogs/
  mechanics/   groups.ts · formal-elements.ts · demo-elements.ts
  novel/       …
  your-id/     新建后在 catalogs/index.ts 的 BUILTIN_CATALOGS 登记
