app-ui — 产品聊天面

产品薄壳窗口。只经 ui.rpc 调 appChat.send，不 inject agentLoop。观测台只负责 openPlugin('app-ui')。

id: app-ui provides: appUi inject: appChat · trajectory? · sandbox? bundle: app
用途 服务 API 组合 给后续 AI 已知问题

1. 用途与边界

一句话：产品窗口是插件，不是观测台硬编码页面。壳只负责 openPlugin('app-ui')。

  • 管：窗口布局、气泡、New Session、右栏本轮轨迹、顶栏沙箱 root、ui.rpc 白名单
  • 不管：agentLoop、默认提示词、模型、会话落盘、观测台注册表、轨迹写入

2. 提供的服务

服务名 APP_UI_SERVICE = 'appUi'。消费方：ctx.appUi 或 ctx.get('appUi')。

字段作用
title窗口标题（当前 App demo）

ui.rpc：{ appChat: ['send', 'cancel'], trajectory: ['latest', 'list', 'snapshot'], sandbox: ['info', 'list'] }。弹窗只能调这些。轨迹 / 沙箱是可选 inject。工作流 Demo 在 app-workflow。

3. Profile 复合

profiles/default → bundles: ["base", "app"]
bundles/base     → logger…agent-loop（能力）
bundles/app      → insert sandbox, workflow, workflow-nodes, app-workflow, app-chat, app-ui

观测台 / 托盘「App demo」= openPlugin('app-ui')。壳不引用 agentLoop，也不渲染聊天 React。

4. 给后续 AI

  • 新 App 面 = 新插件 + bundle insert，不要写回 obs/gui
  • 对话协议改 app-chat；窗口外观改 app-ui/src/page.ts
  • 右栏轨迹只读 trajectory.latest；沙箱顶栏只读 sandbox.info，不要在 app-ui 里写文件
  • 不要把聊天拆成输入框/气泡两个插件
  • 缺 prompt-context 时聊天区尚无人话提示（结构改造 #5）。不要把「卸了还能聊」写成产品设计。

5. 已知问题

  • UI 是插件弹窗 HTML，不是 React；流式 delta 尚未接到气泡
  • 窗口无外层滚动条；对话区与轨迹区可滚但不画滚动条
  • 时间线脚本与 trajectory 插件各一份（traj-view.ts），改展示时两边一起改
  • 沙箱是共享一份 root，New Session 不会换目录
  • 缺组装器时聊天区无提示（结构改造 #5）；轨迹栏已有「未装入」
