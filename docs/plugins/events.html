wizard-harness · core plugin

events — 事件总线服务

把总线暴露为服务：发布 / 订阅 / 查历史 / 清空。观测台「事件」页与弹窗读的是壳账本（内存 + docs/logs/events.jsonl）。

id: events provides: events tier: core
服务 API 清空 给后续 AI

1. 提供的服务

服务名 EVENTS_SERVICE = 'events'。与 ctx.events（观测侧）同名，消费方用 ctx.get('events')。

方法作用
publish(action, target?, payload?)以 plugin:events 发一条
subscribe(listener)订总线，返回取消函数
history(query?)内存环形缓冲（默认 500）
count()缓冲条数
clear()清空内存缓冲，不发事件

2. 清空

观测台事件页 / 事件弹窗的「清空」走壳 IPC：截断 jsonl、清空壳内存、再调 events.clear()。之后新事件照常追加。

3. 给后续 AI

  • 不要把清空做成 HTTP 默认白名单（会毁掉共享账本）
  • 弹窗列表来自 wh.eventsHistory，不是 EventsService.history
