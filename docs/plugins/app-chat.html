app-chat — 产品对话适配

夹在窗口和 agent-loop 之间。默认提示词 / 步数住在这里。没有自己的弹窗。

id: app-chat provides: appChat inject: agentLoop · promptContext · agent · session 无 ui
用途 服务 API 给后续 AI

1. 用途与边界

一句话：App 面不要直接调 agentLoop。换模型循环时只改本插件。

  • 管：send / cancel / listSessions / resumeSession、默认 persona（register 时登记 prompt-context section）、有无工具时的 maxSteps、session 与 agent 绑定
  • 不管：窗口 HTML、气泡、session / llm 实现

2. 提供的服务

服务名 APP_CHAT_SERVICE = 'appChat'。消费方：ctx.appChat。

方法作用
send({ prompt, agentId?, sessionId?, useTools? })转 agentLoop.run；返回含 agentId / sessionId / steps；人设已在 register 时登记 prompt-context
cancel(agentId)转 agentLoop.cancel
listSessions()列出持久化 session 摘要（id、title、updated、preview）
resumeSession(sessionId)绑定 agent 并加载历史消息，供 UI 恢复继续聊

3. 给后续 AI

  • 不要再拆「输入框插件 / 气泡插件」
  • 窗口只调 appChat.send，ui.rpc 不要写 agentLoop
  • 默认人设只登记在 prompt-context（app-chat:persona section）；不要经 loop.run 旁路
