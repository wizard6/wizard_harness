web-pipeline — Web 开发流水线

向 workflow 登记 web.validate / web.deploy / nitron.package。部署目标是静态站，不是 Electron 应用。Nitron 默认 dry-run。

id: web-pipeline provides: webPipeline inject: workflow profile: web-dev 无 ui

边界

一句话：节点种类住在这里。调度器不认识 validate / deploy / nitron。控制台不是插件弹窗，是 plugins/web-pipeline/web 经 API 静态挂载。
  • 管：三种 handler、pipelineGraph、runPipeline、源站/发布目录
  • 不管：顺序调度、Electron 窗口、tools.register、真正的 HTTP 路由到本插件

图

web.validate  → 检查 examples/nitron-web/index.html
web.deploy    → 拷到 $WH_HOME/web-deploy（主产物，浏览器 /site/）
nitron.package → 默认打印 `npx --yes nitron build`；WH_NITRON=1 或 runPipeline({ runNitron:true }) 才构建

启动

pnpm web-dev
# 控制台 http://localhost:8787/
# 站点   http://localhost:8787/site/   （先跑一次流水线）

文件

contracts/src/web-pipeline.tswebPipeline 服务
plugins/web-pipeline/src/nodes.ts三种 handler + 默认图
plugins/web-pipeline/web/浏览器控制台（非 Electron）
examples/nitron-web/产品 demo + nitron.config.json

给后续 AI

  • 再加开发步骤：本插件加 handler 并 registerNode，不要改 schedule.ts
  • 不要给本插件加 ui / Electron 弹窗
  • 不要把 nitron 做成默认 CI 步骤（无 JRE 会失败）；测试只覆盖 dry-run
