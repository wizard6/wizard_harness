query-loop — 可扩展 query 循环

现行 Agent 循环。公开架构：assemble → model → tools → 再 assemble，直到没有 tool_use（end_turn）。兼容 agentLoop.run / cancel。

id: query-loop provides: agentLoop · queryLoop inject: agent · llm · tools · promptContext bundle: base

1. 基本逻辑

一句话：模型决定要不要用工具。要用就执行并把结果写回 session，再问模型；不要用就收工。

while turn <= maxSteps:
  hooks(before-turn)
  assemble + apply          # 当前 session → 模型看见什么
  complete(tools?)          # 模型推理
  hooks(after-model)
  若没有 tool_use → 退出    # end_turn
  对每个 tool:
    hooks(before-tool)
    tools.call              # 结果进 session
    hooks(after-tool)
  hooks(after-turn)

Hook 可返回 continue / skip-tools / stop。新能力挂 hook，不要改 while 骨架。

2. API

服务方法作用
agentLooprun / cancel与旧循环同一契约，app-chat 不用改

3. 给后续 AI

  • 不要把泄露的 Claude Code 源码贴进来。本插件是按公开 query 架构自写的。
  • 不要在 llm / tools / agent 里写循环。出口仍是 complete / call。
  • 扩展用 queryLoop.use，不要复制一份 while。
  • 旧 agent-loop 源码保留，默认 disabled。
