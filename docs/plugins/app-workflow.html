app-workflow — 工作流 Demo

画布窗口：添加节点、拖端口连线、平移缩放。只经 ui.rpc 调 workflowNodes 与 workflow.run。不是聊天 App。

id: app-workflow provides: appWorkflow inject: workflow · workflowNodes bundle: app

1. 用途与边界

一句话：工作流 Demo 是自己的插件窗口。不要把 Run 按钮写回 app-ui。

  • 管：画布（添加节点、拖端口连线、平移缩放）、input.text、Run、把本次 run 的 I/O 画在节点上
  • 不管：调度器、节点 handler、agentLoop、聊天气泡

2. 服务与 RPC

服务名 APP_WORKFLOW_SERVICE = 'appWorkflow'。字段 title = Workflow demo。

ui.rpc：{ workflow: ['run', 'latest', 'get', 'cancel'], workflowNodes: ['demoGraph', 'kinds'] }。

3. Profile 复合

bundles/app → insert sandbox, workflow, workflow-nodes, app-workflow, app-chat, app-ui

托盘「打开 Workflow demo」= openPlugin('app-workflow')。

4. 给后续 AI

  • 画布外观与编辑交互改 plugins/app-workflow/src/page.ts；不要改成表单列表
  • 可添加的种类来自 workflowNodes.kinds，不要在 Demo 里写死 handler
  • 换示例图改 workflow-nodes 的 demoGraph
  • 不要 inject agentLoop / appChat
