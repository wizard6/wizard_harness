workspace — 个人工作台 Demo

浏览器页与 Electron 弹窗共用服务。托盘右键 Open Workspace 打开透桌面 HUD。后续插件用 registerTile 往概览加块。

id: workspace provides: workspace bundle: app · web-dev 托盘 HUD

边界

一句话：工作台是产品壳，不管调度、不管聊天。瓷砖可登记；pnpm web-dev 挂浏览器实心底页，pnpm gui:start 托盘打开透桌面 HUD。
  • 管：snapshot / tiles / loaded / registerTile、浏览器 Demo、Electron ui
  • 不管：workflow 调度、Nitron 构建实现

启动

pnpm gui:start
# 托盘右键 → Open Workspace

pnpm web-dev
# http://localhost:8787/  同一套工作台（浏览器）

后续加插件

inject: { workspace: false }
register(c) {
  const stop = c.workspace?.registerTile({ id, title, blurb, kind: 'soon' | 'panel', view });
  if (stop) c.effect(() => stop);
}
