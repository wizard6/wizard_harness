启发式思考控制 · 经验固化为刚性执行体

需求是积累经验，不是挽救单次任务。 节点长得像工作流，管的不是「AI 做什么」，而是AI 怎么想、按什么想。 执行权在图；人与 AI 只改图。当前只落地 Primitive 仓库，其余先不要实现。

业务目标稳定 允许较长冷启动 必须消除执行方差 AI = 工人，不是导演 behavior / evaluate / guide 出问题只改框架

一句话

把反复出现的「正确想法」铸成可执行思考图：先验骨架冷启动 → 影子对照积累 → 训练轮把 AI 从导演降为格子工人 → 必要时蒸馏成边缘小模型。运行时不准临场发挥。

比程序灵活（图可改、格内可挂 AI），比 Agent 可控（怎么想事先写死，方差闸门默认 0）。先不要实现 Primitive 仓库以外的东西。

积累接受影子 diff = 经验进图。修好这一次 ≠ 积累。
冷启动AI 辅助抽 Seed Graph，人闸门确认。骨架是图，不是 prompt。
刚性体Freeze 之后同一输入必须走出同一条思考路径。

四段机制

1 Seed 先验骨架 · AI 抽规则，人确认

2 Shadow 活轨执行旧图 · 影子只提案

3 Wheels L0→L4 阶梯衰减 AI 依赖

4 Edge 剩余模糊格 → 轻量模型，仍受图调度

点「思考图」看节点；点节点看它控制哪一种「想」。拖训练轮看 AI 徽章消失。

Primitive 仓库（已落地 · 只读）

更小维度的 skill 提示词。不是 Skill：不准目录式直接注入；选用哪几条必须由启发式或 AI 编排（编排未做）。

目标是把「怎么想」的原子经验管起来，供以后按问题类编排。不是给 Agent 再喂一份说明书去挽救单次任务。

behavior 行为 evaluate 评价 guide 指导

behavior做 / 停 / 禁。这一格允许和禁止的动作。
evaluate判。证据够不够、过不过闸、算不算失败。
guide想。先看什么、怎么拆、按什么角色想。

代码：plugins/primitive · 说明：primitive.html

和 Skill 的差

粒度Skill 是一份说明书；Primitive 是一小段思考约束。
注入Skill 可 alwaysApply；Primitive 禁止整包注入。
编排Skill 交给模型临场用；Primitive 必须启发式 / AI 编排。

元评价体系 · Skill 颗粒度

换位思考：用「对方会怎么想」来审自己的默认。

default 纠正补丁：发现默认想法有偏就打一块补丁；偏出现时自己装上，纠正后自己卸掉。

装/卸颗粒度是 Skill 级（针对某一份能力说明书），不是整个人格，也不是单次对话。元评价管补丁该不该在，不替 Primitive 直接注入上下文。未实现。

装上换位思考判定：这份 skill 的默认会漏掉对方视角。
卸掉同类问题连续过闸，偏已纠正，补丁自动卸。
口子装卸仍走同一个改框架口，不准运行时临场改这一步。

和 Agent / 工作流 / Skill 的差

控制在谁手里节点在管什么失败时
传统 Agent判断和节奏都交给 AI临场想下一步做什么再问一次 / 加 prompt
工作流人画「做什么」任务步骤改流程图，但图通常不是思考经验
Skill说明书交给 AI 决定怎么用文本经验执行方式仍临场确定
本框架执行权在图；人与 AI 只改图怎么想、按什么想只准改框架，不准挽救这一次

尚未拍板：跑歪时是停住改图再接着走，还是本轮按旧图走完、改的是下一轮。元评价补丁的自己装/卸由框架触发，还是提议后再过同一改图口。
