Web 优先软件开发架构

基于现有插件底座：API 运行时 + workflow 按图调度 + 浏览器客户端。不经过 Electron。正文见 web-dev-architecture.md。

一句话：开发与部署的主产物是静态 Web；Nitron 只把同一份 Web 打成 APK 作 Android demo。

运行时

浏览器控制台→ obs-api /rpc→ profile web-dev→ workflow + web-pipeline

工作流

web.validate→ web.deploy（主产物 /site/）→ nitron.package（默认 dry-run）

对照

本路径默认 App
壳API + 浏览器Electron GUI
组合base + web-devbase + app
发布静态站桌面弹窗
Android可选 Nitron 包同一份 Web无

启动

pnpm web-dev
# http://localhost:8787/      个人工作台
# 侧栏「发布」                 跑 web-pipeline
# http://localhost:8787/site/ 已部署 Web
