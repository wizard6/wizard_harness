# 插件底座缺口清单（Roadmap）

> 记录日期：2026-08-19
> 定位：wizard-harness 作为"基于插件的底座"的能力盘点与待办。
> 修改方式：**逐个确认后修改**（遵循人机协作确认环）。

## 已具备（✅）

- 插件定义（manifest / api / ui / register / onStart / onStop）
- 注册 / 注销 / 查找（Registrar + contextOf）
- 自动发现（plugins/ 扫描 + _disabled 目录 + disabledPlugins / enableExperimental）
- 依赖装配（inject + boot 拓扑排序 + pending + 级联卸载）
- 服务系统（多提供方 / scope / access 高权限门槛 / 懒加载 factory / contracts 契约包）
- 事件总线 + 观测（CLI / TUI / API / GUI 四端 + 事件化调用 ctx.call + 跨进程网关）
- 插件定级（tier: core/standard/experimental + trusted）
- 测试 77/77

## 缺口（按底座必备度排序）

### 🔴 底座级（先做）

| # | 缺口 | 说明 |
|---|---|---|
| 1 | **插件 schema/配置校验** | manifest 靠代码自觉，无运行时校验（缺 id/版本/非法字段静默畸形） |
| 2 | **插件热重载/热更新** | 改插件需重启整个 harness，无运行时 reload |
| 3 | **插件清理约束** | 有 onStop/effect 撤销，但无"插件必须声明清理"的统一约束（定时器/句柄/订阅） |
| 4 | **版本兼容/冲突检测** | 同名服务不同版本/契约不兼容时无检测 |

### 🟡 完善级（后做）

| # | 缺口 | 说明 |
|---|---|---|
| 5 | 插件元数据/文档自动生成 | README / 能力清单 |
| 6 | 插件市场/包管理 | 远程安装、版本解析（大工程） |
| 7 | 消息路由增强 | 点对点/广播/主题（现有事件总线 + 服务已覆盖基础） |
| 8 | GUI 管理操作 | 观测台里启用/禁用/重载插件 |
| 9 | **配置热更新** | 运行中改配置 → 插件收到通知（ctx.config.onChange） |
| 10 | 对等节点互联 | 网关已有中心化，P2P 对等未做 |

### ⚪ 暂缓/记录

- 网关安全（127.0.0.1 + token 鉴权）——本地场景暂缓
- 插件沙箱——本地可信场景可接受不做
- boot 阶段二失败聚合（半启动状态）
- waitFor 不应实例化懒加载服务
- 浅冻结配置、双事件缓冲（registrar history vs GUI events 数组）

## 推荐顺序

1. #1 schema 校验（成本低，防静默畸形）
2. #9 配置热更新（"能干活"与"只能看"的分水岭）
3. #3 清理约束文档
4. #8 GUI 管理操作 / #2 热重载
