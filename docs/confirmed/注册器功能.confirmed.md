# 注册器功能 · 人类确认文件

> 以下为示例草稿，请改写为你的真实意图；正文不超过 300 字，标题与说明不计入。

1. 在 core/ 实现注册器：register/get/list/has/unregister + 最小事件总线。
2. 插件契约：manifest(id 唯一/版本/输入输出/副作用/依赖) + register 及可选 start/stop。
3. 依赖向内：core 不依赖插件；重复 id 与非法插件抛错。
4. 每次注册/注销/命中发观测事件，统一事件格式，并落盘日志。
5. 验收：注册可查、重复/非法抛错、注销失效、事件可订阅、生命周期钩子按序调用；附单测。
6. 观测方式：事件持久化，分阶段提供 CLI(纯Node) / TUI(ink) / GUI(HTML+Electron桌面)。
7. 每个插件收敛为单一对外接口(api)，并提供轻量独立弹窗页(ui/HTML)。
