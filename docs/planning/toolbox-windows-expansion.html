toolbox · Windows 扩展工具规划

目标：在普通 Windows 电脑上让 Agent / 人工按钮「能干很多事」，但仍可审计、可关、可限。 现状仅 open_folder、git_push 与三种 kind；工作区路径越界已在 runner 拦截。

风险等级（建议写入 config，而不仅是文档）

  • T0 只读 仅读工作区 / 只读系统信息，无副作用
  • T1 工作区写 仅在工作区内创建、修改、删除文件
  • T2 本机交互 打开路径/URL、剪贴板、通知、启动已白名单程序
  • T3 进程/网络 启停进程、装包、访问网络；需超时 + 白名单 + 审计
  • T4 高危 注册表写、计划任务、提权、全盘操作；默认关闭，仅人工 + 二次确认

横切限制（所有扩展都应具备）

  • agentCallable / humanOnly：弹窗可点、Agent 默认禁 T3+
  • confirm：T3+ 执行前 GUI 或 workflow 确认卡
  • audit：写入 events / logger（谁、何时、参数摘要、退出码）
  • timeoutMs + 输出截断（已有）+ 并发上限
  • 禁止裸 cmd /c {{任意}}；Agent 只调具名 box.*，参数 schema 校验

一、Git 与版本（优先落地，T0–T1）

工具名等级作用Windows 实现要点必加限制优先级
box.git_status T0 查看变更文件与分支 git status -sb 仅 workspace；输出截断 P1
box.git_diff T0 查看 diff（可限路径） git diff -- {{path}} path 必须在工作区内；--no-ext-diff P1
box.git_pull T1 拉取远程 git pull --ff-only 禁止 --rebase 除非显式开关；失败不自动 force P1
box.git_commit T1 仅 commit（不 push） git add 可限路径 + git commit -m 默认 humanOnly 或需 confirm；钩子不可跳过 P2
box.git_push T3 已有：提交并推送 现有 shell 模板 改为 confirm + 禁止 push 到 main 除非 allowBranches P1 加固
box.git_stash T1 暂存/恢复工作区 git stash push/pop 仅 workspace 仓库；pop 前 diff 预览 P3

二、文件与工作区（T0–T1）

工具名等级作用Windows 实现要点必加限制优先级
box.list_dir T0 列目录（树或平铺） Node readdir 或 Get-ChildItem 深度/条目上限；跳过 node_modules P1
box.find_files T0 按 glob 找文件 复用 dev-tools glob 逻辑 最多 N 条；禁止 **/* 无界 P1
box.read_file T0 读文本片段 offset + max_chars 与 code-browser 分工或委托；二进制拒绝 P2
box.write_file T1 写/追加文件 原子写临时文件再 rename 扩展名白名单；单文件大小上限 P2
box.delete_path T1 删文件/空目录 fs.rm 仅文件 禁止删 .git；目录非空需 confirm P3
box.zip_workspace T1 打包工作区备份 PowerShell Compress-Archive 输出必须在 workspace；排除大目录 P3
box.open_folder T2 已有：资源管理器打开 explorer.exe 测试环境 humanOnly；Agent 可只返回路径 P1 已有
box.reveal_file T2 在资源管理器中选中文件 explorer /select,"path" 同 open_path 边界 P2

三、开发与构建（T1–T2）

工具名等级作用Windows 实现要点必加限制优先级
box.pnpm_install T1 安装依赖 pnpm install 仅 workspace；长超时；禁止 --ignore-scripts 除非配置 P1
box.pnpm_run T1 跑 package.json scripts pnpm run {{script}} script 白名单（build/test/lint/quality） P1
box.run_tests T1 跑 vitest / 指定路径 pnpm vitest run {{path}} path 限 plugins/* 或 test 目录 P1
box.quality_check T1 跑仓库 quality 门禁 pnpm quality 固定命令，无自由参数 P2
box.open_in_cursor T2 用 Cursor 打开文件/行 cursor -g file:line 或 URI 路径限 workspace；humanOnly 默认 P2
box.open_url T2 系统浏览器打开链接 已有 kind open_url URL scheme 白名单（http/https） P2

四、进程、网络与系统信息（T0–T3）

工具名等级作用Windows 实现要点必加限制优先级
box.env_print T0 查看环境变量（脱敏） Node process.env 过滤 屏蔽 *KEY* *TOKEN* *SECRET* P2
box.which T0 解析可执行文件路径 where.exe / Get-Command 只读；无执行 P2
box.port_list T0 查看监听端口 netstat -ano 或 Get-NetTCPConnection 输出截断；不杀进程 P2
box.process_list T0 按名查进程 Get-Process -Name 仅列信息 P3
box.kill_process T3 结束卡死进程 taskkill /PID 仅允许白名单进程名；禁止 PID 0/系统进程；confirm P3
box.curl_get T3 HTTP GET 探测 curl.exe 或 fetch 域名白名单；响应大小上限；无 POST 体 P3
box.ping_host T2 网络连通性 ping -n 4 主机名白名单或内网段 P3

五、Windows 桌面交互（T2，偏「为所欲为」但可控）

工具名等级作用Windows 实现要点必加限制优先级
box.clipboard_read T2 读剪贴板文本 PowerShell Get-Clipboard 仅文本；长度上限；默认 humanOnly P2
box.clipboard_write T2 写入剪贴板 Set-Clipboard 长度上限；审计日志 P2
box.notify T2 桌面通知 BurntToast / WinRT 或 tray 标题+正文长度；无 HTML P2
box.screenshot T3 截屏（全屏/窗口） .NET / PowerShell 默认关闭；隐私敏感；存 workspace 临时目录 P3
box.run_app T2 启动白名单程序 Start-Process exe 白名单：notepad、calc、explorer、cursor P2
box.send_keys T4 模拟按键（自动化） AutoHotkey / UIAutomation 默认禁用；仅 workflow 人工触发 不建议

六、包管理与服务（T3–T4，默认关）

工具名等级作用Windows 实现要点必加限制优先级
box.winget_search T0 搜索可安装包 winget search 只读 P3
box.winget_install T3 安装软件 winget install --id 包 ID 白名单；confirm；非静默需人工 P3
box.service_status T0 查询 Windows 服务状态 Get-Service 服务名白名单 P3
box.registry_read T0 读注册表键值 Get-ItemProperty 路径白名单（HKCU\\Software\\…） P3
box.registry_write T4 写注册表 Set-ItemProperty 默认禁用；备份 + confirm 不建议
box.scheduled_task T4 创建计划任务 schtasks 默认禁用；仅指向 workspace 内脚本 不建议
box.run_elevated T4 提权执行 UAC RunAs 永不给 Agent；仅人工 禁止

七、与现有插件分工（避免重复造轮子）

能力建议
读代码 / grep / glob优先委托 dev-tools 工具，toolbox 只做「一键按钮」封装
网页搜索阅读用 web-tools，toolbox 不重复
发邮件封装 send-email 技能脚本 → box.send_email（T3，confirm）
定时任务编排长周期用 timer 插件，不用 schtasks 替代
记忆 / 人格用 memory / persona，不进 toolbox

八、推荐实施顺序（3 个里程碑）

M1 · 安全底座（先做机制再加工具）

  • config 增加 tier、agentCallable、confirm、allowBranches
  • runner 审计事件 toolbox/run
  • 加固现有 git_push（拆分 commit/push、保护 main）

M2 · 日常开发 P1 包（约 10 个 box.*）

  • git_status / git_diff / git_pull
  • pnpm_install / pnpm_run / run_tests
  • list_dir / find_files

M3 · Windows 体验 P2（人机协作）

  • notify / clipboard_* / reveal_file / open_url
  • port_list / env_print
  • send_email 封装（若你需要邮件按钮）
