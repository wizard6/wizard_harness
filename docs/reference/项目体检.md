## 架构现状

```
运行时壳（加载插件）          观测器壳（只读 jsonl）
┌───────────┐  ┌───────────┐   ┌────────┐ ┌────────┐
│ GUI       │  │ API       │   │ CLI    │ │ TUI    │
│ (Electron)│  │ (HTTP+RPC)│   │        │ │        │
└─────┬─────┘  └─────┬─────┘   └────────┘ └────────┘
      └── assembleRuntime（core/shell.ts）──┘
              profile/bundle 组合 → discover → validatePlugin 预检
              → boot（inject 拓扑）→ pending / failures 上报
```

**产品路径（fail-closed）：**

```
app-ui → appChat → agentLoop.run
                      ├ observe：promptContext.assemble（必选）
                      ├ think：llm.complete（onDelta → llm/delta）
                      └ act：tools.call（scoped，经 assembly.tools）
agent = scope + session 绑定；tools / prompt 按 agent.ctx overlay
```

依赖方向：core 不依赖插件；插件依赖 core 契约（`@wizard-harness/core` / `@wizard-harness/contracts` / `@wizard-harness/plugin-sdk`）。

## Scope 模型（当前代码）

| 概念 | 位置 | 行为 |
| --- | --- | --- |
| `ScopeKey` | `core/src/scope/keys.ts` | exact scope 标识；agent 句柄携带 |
| `ScopedLayers` | `core/src/scope/layers.ts` | 全局层 + overlay；`bind(ctx)` 后读写限定在 agent scope |
| tools | `plugins/tools` | 注册进全局；`listIn(scope)` / `bind(ctx)` 只返回当前 agent 可见工具 |
| prompt-context | `plugins/prompt-context` | `bind(agent.ctx)` 后 section/context/tools 登记带 scope |
| agent-loop | `plugins/agent-loop` | 每步 `tools.bind(handle.ctx)` + assemble |
