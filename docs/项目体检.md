```
运行时壳（加载插件）          观测器壳（只读 jsonl）
┌───────────┐  ┌───────────┐   ┌────────┐ ┌────────┐
│ GUI       │  │ API       │   │ CLI    │ │ TUI    │
│ (Electron)│  │ (HTTP+RPC)│   │        │ │        │
└─────┬─────┘  └─────┬─────┘   └────────┘ └────────┘
      └── assembleRuntime（core/shell.ts）──┘
              createHarness → discoverPlugins
              → disabled/experimental 过滤 → boot（inject 拓扑）
```

依赖方向：core 不依赖插件；插件依赖 core 契约（`@wizard-harness/core`）。

## 遗留项（按确认稿 v2 边界分类）

**待触发（方向 3）**
- `Dispatcher` 未接入 `PluginContext`（建议 `ctx.dispatcher` 受限视图，不重载 `ctx.emit` 观测语义）。等首个协作型插件用例，或按"基座能力齐备"要求触发。

**待设计（方向 4）**
- 通用 UI 桥：GUI 弹窗 IPC（`wh:exec-command` / `wh:events-history`）硬编码对应 console / events 插件；通用化需单独安全设计（插件 api 白名单暴露给 preload）。

**小项**
- `manifest.dependencies` 仅发警告不阻断加载（`dep-missing` 事件 + 壳侧 console.warn）——确认稿约定即为"发警告"，如需改为硬校验需更新确认稿。
- 配置无 schema 校验（`config[pluginId]` 与 `manifest.config` 直接合并）。
- `discoverPlugins` 只校验 `id + register`，其余元数据未验证。

**边界外（确认稿明确不做）**
- 热插拔、路由、沙箱隔离、用户权限系统。
